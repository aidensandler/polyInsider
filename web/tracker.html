Historical test vs. live tracker

The historical team analysis evaluated whether earlier wallet scores predicted later wallet performance. The market model predicts YES/NO resolution probability before resolution, while the wallet model predicts future wallet outperformance using only earlier known outcomes. We evaluate each separately. Neither claims to identify actual possession of private information.

To move from the synthetic demonstration to a real-data live tracker, import frozen historical trade snapshots and outcomes, train the model, run the read-only API collector and retain the generated CSV predictions.
