POLYINSIDERS - ECE 473 (Aiden Sandler & Emilly Antero)

1. Read README.md (project overview and honest results), then README_APP.md (app details).
2. In Terminal in this folder:
     python3 -m venv .venv
     source .venv/bin/activate
     python -m pip install -r requirements.txt
     python -m pytest -q                  (16 tests)
     python3 -m http.server 8000 --directory web      (static preview of the saved snapshot)
   or, for live collection (needs internet):
     python -m polyinsider.cli serve --live --interval 120 --port 8000
3. Open http://localhost:8000
4. See docs/DEEP_EXPLANATION.md for methods and slides/ for the editable deck.

Do NOT run `python -m polyinsider.cli demo` unless you want to overwrite the real
models in data/run/ with a synthetic demo. The raw trade archive is not in this
repository; full retraining needs the separately kept data (see analysis/README.md).
